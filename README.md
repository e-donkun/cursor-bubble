# CursorBubble

マウスやキーボードの操作内容を、**カーソルのすぐ横に吹き出しで表示**する Windows 用ツールです。
授業で PC 画面を投影しながら操作説明をするときに、「いま何をしたか」を生徒に見えるようにします。

| 操作 | 表示例 |
| --- | --- |
| クリック | `左クリック` `右クリック` `ダブルクリック` `ホイールクリック`（クリック位置に波紋） |
| ドラッグ | `ドラッグ` → `ドロップ` |
| ホイール | `スクロール ↓` `Ctrl + スクロール ↑（拡大）` |
| ショートカット | `Ctrl + C（コピー）` `Alt + Tab（ウィンドウ切り替え）` `Win + Shift + S（画面の切り取り）` |
| 特殊キー | `Enter` `Tab` `Backspace ×3` `半角/全角` `変換` `F7` `↓ ×4` |
| 修飾キー付きクリック | `Ctrl + 左クリック` `Shift + 左クリック` |

## ビルド方法

追加のインストールは不要です。Windows 11 に標準で入っている .NET Framework 4.x の C# コンパイラを使います。

1. このフォルダーを PC にコピーする
2. `build.bat` をダブルクリックする
3. 同じフォルダーに `CursorBubble.exe` ができる

## 使い方

- `CursorBubble.exe` を起動すると、タスクトレイ（画面右下）に青いアイコンが出ます。
- **Ctrl + Alt + F9** で表示のオン／オフを切り替えられます。
- トレイアイコンを右クリックするとメニューが出ます。

| メニュー | 内容 |
| --- | --- |
| 操作を表示する | 表示のオン／オフ |
| 文字キーも表示する | 既定はオフ。オンにすると `A` や `1` などの文字キーも表示 |
| ショートカットの説明を表示する | `Ctrl + C（コピー）` の「（コピー）」の部分 |
| クリック位置に波紋を表示する | クリックした場所に輪を表示 |
| 表示の大きさ | 小／中／大／特大（投影時は「大」以上がおすすめ） |
| 終了 | 終了する |

設定は `%APPDATA%\CursorBubble\settings.txt` に保存されます。

## 注意点

- **パスワードについて**：既定では文字キー単独の入力は表示しません（ショートカットと特殊キーだけ）。
  「文字キーも表示する」をオンにしている間は、パスワード入力も画面に出るので注意してください。
- **管理者権限のウィンドウ**：このツールは一般ユーザー権限で動きます。
  管理者として実行されているアプリ（UAC の確認画面、管理者のコマンドプロンプトなど）を操作している間は、
  Windows の仕様で入力を検知できず、表示されません。
- スタートメニューなど一部のシステム画面の上では、吹き出しが隠れることがあります。
- 入力内容は表示に使うだけで、ファイルへの保存や通信は一切行いません。
- キー入力を監視する仕組み（低レベルフック）を使うため、セキュリティソフトによっては警告が出ることがあります。

## しくみ

- `SetWindowsHookEx` の `WH_MOUSE_LL` / `WH_KEYBOARD_LL`（ユーザーモードの低レベルフック）で操作を検知
- クリックを透過する最前面のレイヤードウィンドウ（`WS_EX_LAYERED | WS_EX_TRANSPARENT`）に吹き出しを描画
- ソースは `src/CursorBubble.cs` の 1 ファイルです

## ダウンロード

ビルド済みの `CursorBubble.exe` は [Releases](https://github.com/e-donkun/cursor-bubble/releases) からダウンロードできます。
署名のない exe のため、初回起動時に「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を選んでください。
